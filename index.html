CodePrint++


A browser tool to prepare PDF source code submissions for the AP Computer Science Principles Create Task.

This utility is based upon Baker Franke's original CodePrint utility with slight functionality improvements.








JavaScript / P5.js Python
Steps:
  1. Paste your code into the text box above.
  2. Check your code to make sure that it meets the Create Task requirements.
  3. Draw shapes on the PDF to highlight important code segments (if applicable)
  4. Print to PDF from the browser by clicking the "Print Code" button.
Note: It is highly recommended that you only use one rect and one oval for the AP Performance task to avoid confusing the reader. However, in some circumstances your abstraction or algorithm may get split up, requiring you to need more than one shape to mark the appropriate sections.
